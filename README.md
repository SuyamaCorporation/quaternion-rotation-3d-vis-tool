# クォータニオン回転3Dオイラー角変換ビジュアライザー

クォータニオン(w,x,y,z)とオイラー角(Yaw/Pitch/Roll)を双方向リアルタイム変換し、3×3回転行列も同時表示。Canvas2DでワイヤーフレームキューブとXYZ座標軸を簡易3D投影で描画。Pitch±90°付近のジンバルロック発生をアニメーション警告で検出。Slerp球面線形補間デモでは2つのクォータニオン間のなめらかな回転遷移をスライダーで体験できる。

## 使い方

オイラー角スライダーを動かすか、クォータニオン欄に数値を入力すると3Dビューがリアルタイム更新される。「正規化」ボタンで単位クォータニオンに変換。「Slerp補間デモ」ボタンで自動アニメーション実行。
